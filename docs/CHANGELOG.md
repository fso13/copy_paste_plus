# Журнал изменений

Все заметные изменения проекта фиксируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект следует [Semantic Versioning](https://semver.org/lang/ru/).

## [Unreleased]

## [1.1.2] — 2026-08-12

### Добавлено
- Цвета типов данных в истории (text / url / json / shell / javascript / css / image / secret)
- Настройки → «Цвета типов»: выбор цвета (палитра + HEX) и сброс к значениям по умолчанию

### Изменено
- Полоска и бейдж элемента окрашиваются по типу; secret — отдельный (красный по умолчанию)

## [1.1.1] — 2026-08-12

### Добавлено
- Встроенная справка в настройках: сниппеты (`{{name}}`), быстрый выбор `1`–`9`, secret, шифрование, авто-вставка и другие темы
- Ссылка на сайт документации из настроек

### Исправлено
- Падение после диалога сниппета с плейсхолдерами (`TextEditingController` after dispose / Duplicate GlobalKey)
- Корректное закрытие окна: дерево виджетов размонтируется после анимации диалогов

### Изменено
- Актуализированы скриншоты в README и на GitHub Pages (сниппеты, справка, настройки)

## [1.1.0] — 2026-08-12

### Добавлено
- Сниппеты с плейсхолдерами `{{name}}` (вкладка «Сниппеты»)
- Трансформации текста в меню элемента: Trim, JSON, Base64, URL, slug, регистр, snake/camel
- Картинки и скриншоты в истории (PNG на диск, превью в списке)
- Опциональное шифрование истории на диске (AES-GCM, ключ в Keychain)
- Скрипт `scripts/codesign_and_notarize.sh` и поддержка секретов в CI для Developer ID / notarize

### Изменено
- Bundle ID: `com.fso13.copyPastePlus`, имя приложения `CopyPastePlus`
- DMG собирается из `CopyPastePlus.app`

## [1.0.8] — 2026-08-12

### Добавлено
- Реальный автозапуск при старте macOS через `SMAppService` (macOS 13+)
- Опциональная авто-вставка выбранного фрагмента (`⌘V` в предыдущее приложение); тумблер в настройках, по умолчанию выкл.; требуется Универсальный доступ
- Клавиатурная навигация: `↑`/`↓`, `Enter`, быстрый выбор `1`–`9`, `Esc` закрывает окно
- Игнор приложений: копирования из списка (по умолчанию парольные менеджеры) не попадают в историю
- Маскировка чувствительных данных (`••••`) с раскрытием «глазом»
- Ручной тип `secret` в меню элемента (⋮): пометить / снять; комментарий при маскировке остаётся видимым
- Захват источника копирования (bundle id / имя приложения) для фильтрации

### Изменено
- Настройки: секции «Вставка» и «Приватность»
- Тумблер «Запуск при старте системы» синхронизируется с Login Items ОС

## [1.0.7] — 2026-08-12

### Добавлено
- Секция Changelog на GitHub Pages с автосинхронизацией из корневого `CHANGELOG.md`

### Исправлено
- Сборка CI: исчерпывающий `switch` по `HotKeyModifier` (`capsLock`, `fn`) для Dart 3.12

## [1.0.6] — 2026-08-12

### Добавлено
- Статичный GitHub Pages лендинг в стиле fso13 (`docs/index.html`)

### Исправлено
- Горячая клавиша после перезапуска сбрасывалась на значение по умолчанию (не сохранялась в настройках)

## [1.0.5] — 2026-08-11

### Изменено
- Flutter SDK **3.44.9** / Dart **3.12.2** (закрывает CVE-2026-27704 в pub)
- Обновлены зависимости без известных CVE (OSV): `uuid` 4.6.0, `shared_preferences` 2.5.5, `window_manager` 0.5.2, `flutter_lints` 6.0.0, `package_info_plus` 10.2.1 и транзитивные пакеты
- Проект только для macOS: удалены платформы Android / iOS / Linux / Windows / Web и неиспользуемые артефакты

## [1.0.4] — 2026-08-11

### Добавлено
- Сохранение стилей буфера (HTML/RTF): при копировании из IDE подсветка сохраняется при вставке в Word и другие rich-text приложения; в plain-text поля вставляется только текст
- Комментарии к избранному: произвольный текст, отображается под контентом
- Кнопка «⋮» в элементе списка для открытия контекстного меню

### Изменено
- Комментарии к избранному отображаются более мелким текстом

## [1.0.3] — 2026-08-11

### Добавлено
- Бренд-марка CopyPaste**Plus** (иконка буфера с «+», two-tone подпись)
- Glitch-эффект надписи при наведении (как на fso13)
- Горячая клавиша `⌘F` для фокуса поиска

### Изменено
- Интерфейс главного окна и настроек приведён к макетам (карточки, вкладки, футер)
- Иконка приложения и трея в том же стиле, что и в UI
- Убраны декоративные «светофоры» в шапке окна

### Исправлено
- Подсказка `⌘F` в поиске не соответствовала реальному поведению

## [1.0.2] — 2026-08-11

### Добавлено
- CONTRIBUTING.md, CODE_OF_CONDUCT.md
- Шаблоны Issue и Pull Request для GitHub
- Документация `docs/` со скриншотами и кратким гайдом
- Бейджи в README (CI, лицензия, релиз, платформа)
- Кнопка «Завершить работу» в настройках

### Исправлено
- Дублирующая иконка в меню-баре (убран нативный NSStatusItem, остался только Flutter `system_tray`)

## [1.0.1] — 2026-08-11

### Добавлено
- Версия и номер сборки в настройках
- Переключатель темы: системная / светлая / тёмная (UI в стиле Dracula)
- Проверка обновлений через GitHub Releases (уведомлять / авто / выкл.)
- Скрипт сборки DMG (`scripts/create_dmg.sh`)
- GitHub Actions: сборка DMG и публикация в релизе
- Пасхалка: Pong после 13 кликов по блоку «О приложении»
- Шуточные пустые состояния и статус-строка

### Исправлено
- Удаление и снятие с избранного не обновляли список
- Очистка истории больше не очищает избранное
- Кривое выравнивание поля поиска

### Изменено
- Интерфейс переработан под визуальный стиль портфолио

## [1.0.0] — 2025-09

### Добавлено
- История буфера обмена и избранное
- Глобальный хоткей (`⌘⇧C`)
- Иконка в меню-баре
- Настройки: хоткей, лимит истории, запуск при старте системы
- Нативный мониторинг буфера обмена на macOS
